# Filament Label Studio

Browser editor for 40 × 14 mm filament labels. Create and export a PNG, then import it into the Nelko app. PLA+ is first; the generic “Andere” material entry has been removed. Label typography was increased: manufacturer 38 px, material 42 px, finish 25 px and color 34 px.

For direct Nelko P21 Bluetooth Classic SPP printing on Windows, use the separate \`windows-app/STARTEN.bat\`. Requirements: Windows 10/11, Python 3.10+, Edge WebView2 Runtime, paired P21 and outgoing Bluetooth COM port.
