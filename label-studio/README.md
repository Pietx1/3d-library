# Filament Label Studio

The browser editor creates and exports 40 × 14 mm label PNG files. PLA+ is first, “Andere” is removed, and the manufacturer/material/finish/color type sizes are enlarged to 38/42/25/34 px.

The top link returns to the 3D Library. For Nelko P21 Bluetooth Classic SPP direct printing on Windows, download and extract `Filament-Label-Studio-Windows-v1.4.zip` and run `STARTEN.bat`. Requirements: Windows 10/11, Python 3.10+, Edge WebView2 Runtime, a paired P21 and an outgoing Bluetooth COM port.
